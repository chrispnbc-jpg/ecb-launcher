# ECB Launcher

Installers and updates for the ECB Launcher, the desktop launcher for East Coast Bazaar games.

**Download:** [latest release](https://github.com/chrispnbc-jpg/ecb-launcher/releases/latest), then run `ECB-Launcher-Setup-<version>.exe`.

Already installed? The launcher updates itself from these releases.

This repository holds release files only. The source code stays private at the studio.
